## 📌 Phân Tích 10 Chương Slide

### 🔹 Chương 00: HSF Course Introduction (13 slides)
* Giới thiệu môn học, mục tiêu nghề nghiệp (Hibernate + Spring là chuẩn công nghiệp).
* Môi trường học tập: JDK 21, IntelliJ IDEA, Scene Builder 23.
* Quy chế đánh giá: PT1 & PT2 (10%), AS1 & AS2 (10%), PE (25%), Group Project (25%), Final Exam (30%).
* Điều kiện qua môn: Mọi điểm thành phần > 0, PE $\ge 4.0$, FE $\ge 4.0$, Điểm tổng kết $\ge 5.0$.

### 🔹 Chương 01: JPA, JPA Mapping (77 slides)
* Khái niệm ORM (Object Relational Mapping).
* Kiến trúc JPA: `EntityManagerFactory`, `EntityManager`, `EntityTransaction`.
* Annotation cơ bản: `@Entity`, `@Table`, `@Id`, `@GeneratedValue`, `@Column`.
* Mapping quan hệ: `@OneToOne`, `@OneToMany`, `@ManyToOne`, `@ManyToMany`.
* Vấn đề FetchType (`LAZY` vs `EAGER`) và Cascade (`PERSIST`, `MERGE`, `REMOVE`, `ALL`).
* Vòng đời Entity: New/Transient, Managed, Detached, Removed.
* Ngôn ngữ truy vấn JPQL (Java Persistence Query Language).

### 🔹 Chương 02: Introduction to Spring Framework (60 slides)
* Lịch sử và vai trò của Spring Framework trong hệ sinh thái Java Enterprise.
* Khái niệm then chốt: **IoC (Inversion of Control)** và **DI (Dependency Injection)**.
* Spring Container / ApplicationContext.
* Các kiểu Dependency Injection: Constructor Injection vs Setter Injection vs Field Injection (Khuyến khích dùng Constructor Injection).
* Annotation: `@Component`, `@Service`, `@Repository`, `@Controller`, `@Autowired`, `@Qualifier`, `@Value`.
* Bean Lifecycle & Bean Scopes (Singleton, Prototype).

### 🔹 Chương 03: Spring Boot Concepts (35 slides)
* Nỗi đau cấu hình XML và thiết lập máy chủ Tomcat thủ công của Spring truyền thống.
* Ưu điểm Spring Boot: Opinionated Defaults, Embedded Server (Tomcat tích hợp), Không cần sinh code XML.
* Các gói `spring-boot-starter-*` (web, data-jpa, test).
* Cơ chế Auto-configuration (`@SpringBootApplication` = `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan`).
* Quản lý file cấu hình: `application.properties` vs `application.yml`, Profiles (`dev`, `prod`).

### 🔹 Chương 04: Spring Data JPA (36 slides)
* Đột phá so với JPA truyền thống: Loại bỏ boilerplate code của `EntityManager`.
* Khái niệm Repository Pattern: Kế thừa `CrudRepository` và `JpaRepository<T, ID>`.
* Phương thức truy vấn tự sinh (Query Method Creation by Method Name): `findByName`, `findByAgeGreaterThan`, `findDistinctBy...`.
* Tùy biến truy vấn với `@Query`: JPQL queries và Native SQL queries.
* Hỗ trợ phân trang và sắp xếp: `Pageable`, `PageRequest`, `Sort`.

### 🔹 Chương 05: Spring MVC (71 slides)
* Mô hình MVC trong lập trình Web: Model, View, Controller.
* Kiến trúc bên trong của Spring MVC:
  * `DispatcherServlet` (Front Controller).
  * `HandlerMapping` (Tìm controller phù hợp).
  * `Controller` (Xử lý nghiệp vụ).
  * `ViewResolver` (Biên dịch View template như Thymeleaf/JSP).
* Các annotation điều hướng: `@Controller`, `@RequestMapping`, `@GetMapping`, `@PostMapping`, `@ModelAttribute`.

### 🔹 Chương 06: Spring Web Development (RESTful API) (42 slides)
* Chuyển đổi từ mô hình Server-Side Rendering sang REST API Kiến trúc Client-Server hiện đại.
* Các nguyên lý RESTful: Stateless, Resource-based URLs, Chuẩn HTTP Verbs.
* Annotation cho REST API:
  * `@RestController` (kết hợp `@Controller` + `@ResponseBody`).
  * `@RequestBody`, `@PathVariable`, `@RequestParam`, `@RequestHeader`.
  * `ResponseEntity<T>` để kiểm soát HTTP Status Code và Headers.
* Định dạng dữ liệu JSON với Jackson library.
* DTO (Data Transfer Object) Pattern và Validation (`@Valid`, `@NotNull`, `@Size`, `@Email`).
* Xử lý lỗi toàn cục (Global Exception Handling) với `@RestControllerAdvice` và `@ExceptionHandler`.

### 🔹 Chương 07: Build Simple App with Data Access using Spring, JDBC, ORM & Thymeleaf (28 slides)
* Tích hợp toàn diện: Kết nối Database qua Spring Data JPA, viết Service nghiệp vụ, hiển thị ra giao diện web với Thymeleaf template.
* Xử lý Form Submission, binding dữ liệu hai chiều, hiển thị danh sách và phân trang trên Web.

### 🔹 Chương 08: Introduction to JavaFX (70 slides)
* Tổng quan về GUI framework hiện đại cho Java Desktop: JavaFX.
* Cấu trúc kiến trúc JavaFX: Theater Metaphor (Stage = Cửa sổ, Scene = Cảnh phim, Scene Graph = Cây đối tượng UI Node).
* Công cụ Scene Builder: Kéo thả UI trực quan, tách bạch thiết kế giao diện (file `.fxml`) và code logic (Java Controller).
* Các Layouts chính: `BorderPane`, `VBox`, `HBox`, `GridPane`, `AnchorPane`.
* Các Controls thông dụng: `Label`, `TextField`, `Button`, `TableView`, `ComboBox`, `DatePicker`.
* Cơ chế Event Handling: `setOnAction`, `EventHandler`.

### 🔹 Chương 09: Build Application with JavaFX & JPA (36 slides)
* Kết hợp giao diện JavaFX với tầng dữ liệu Hibernate/JPA.
* Mô hình MVC trên Desktop:
  * View: File FXML được chỉnh sửa qua Scene Builder.
  * Controller: Class Java gắn `@FXML` xử lý sự kiện bấm nút, gán dữ liệu.
  * Model/Data Access: Entity JPA và Repository/DAO kết nối Database.
* Quản lý trạng thái ObservableList (`FXCollections.observableArrayList()`) để TableView tự động cập nhật khi thêm/sửa/xóa.
* Thực chiến xây dựng hoàn chỉnh ứng dụng Desktop CRUD.
